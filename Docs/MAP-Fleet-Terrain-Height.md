# 3D 集群移动：离地高度与地表检查

2026-10-17 在正常运行的 CesiumWorld 中复现了地下画面。既有模拟位置为 **40 米椭球高**，实际加载的地表碰撞面约为 **49.109 米椭球高**，因此无人机在地表下约 **9.109 米**。椭球高是绝对高度，不等于离地高度；此前的离线平面验证没有覆盖这个差异。

## 当前操作

1. 框选无人机，切换到 3D，等待地表加载。
2. 3D 集群移动默认输入“目标离地高度”。它表示主选锚点在目标地表上方的高度。面板同时显示当前离地高度、地表椭球高和目标椭球高。有效的当前离地高度会保留；低于地表的初始位置使用 30 米作为预览建议。
3. 点击实际地表选择目标。目标椭球高 = 目标地表椭球高 + 输入的离地高度。其他成员保持相对经纬度和高度差，因此各成员的离地高度可以随地形有所不同。
4. 高级按钮可切到椭球高模式；切换基准保留实际目的位置。低于地表的目标会明确告警并禁用确认。
5. 旧模拟位置低于地表时，可点击“将模拟编队抬升至地上”。这只生成垂直预览，再次确认后才通过现有 `execution_group_move` 抬升整个编队，使各成员在当前加载地表上方至少约 30 米。此恢复操作仅供空闲的 Mock 编队使用，仍受 Backend 占用和角色权限检查。

地图不会凭空抬高模型或修改历史执行快照。模型和预览使用 Backend 确认的同一椭球高；恢复创建真实的 **Mock 执行记录**，不是显示偏移。2D 保留当前绝对高度移动的既有行为。

## 地表与相机

- 采样沿地理垂直方向查询已加载的 WorldStatic 碰撞面，忽略无人机、航点与路径演员，防止把飞机或预览线当成地面。采样失败不伪造零米地表。
- 3D 选点命中实际已加载的碰撞面。预览检查每个成员的起点、终点和沿途约 10 米间隔的采样，单条最多 1024 段；确认前强制重新采样。普通移动要求采样位置至少约 1 米间隙；地下 Mock 恢复只允许显式的垂直上升，终点要求约 30 米间隙。
- 地形没有加载或采样路径与地表相交时不能确认。该检查针对当前加载碰撞面及其采样分辨率，不代表完整的障碍物避障、地图精度保证或真实飞行认证。
- 自由浏览的 3D 相机保持在已加载地表上方至少约 5 米。Camera Lock 原有入口和冻结行为保持不变，锁定期间不会因地表采样移动相机。
- 继续使用 Route V2 的单一预览 / 执行展示所有权；选择和集群移动不切换 Video Target。

## 已完成的实际地图验证

原生鼠标与键盘验证使用 `Scripts/FleetTerrainHeight/qa_host.py` 管理的独立 Mock 数据，地图为在线 **CesiumWorld**，不是离线假地形。HTTP 仅用于 GET 取证。数值探针记录模型、Backend 位置、实际加载地表及相机高度，单独标明为程序化测量。

| 验证 | 结果 |
| --- | --- |
| 地下位置重现 | 4 架原始高度 40 米；主选地表 49.109016 米，离地 -9.109016 米，模型与 Backend 高度一致。 |
| 恢复预览 | 鼠标点击恢复，只出现四条垂直预览；执行记录仍为 0。 |
| 确认恢复 | 4 个 GROUP_MOVE 全部 COMPLETED，最终椭球高 79.109016 米，各成员离地约 30.000–30.423 米。 |
| 正常 3D 移动 | 输入离地 40 米并点击地表，最终主选椭球高 90.088119 米、离地 40 米，4 架全部完成并保持队形。 |
| 地下目标拦截 | 同一目标切到椭球高并输入 40 米，出现地表相交告警、确认禁用，执行记录仍为此前的 4 个已完成记录。改回有效离地高度后才产生第二组。 |

## 回归与诊断记录

`Scripts/FleetTerrainHeight/verify.py` 为每个用例创建新的 Mock 数据和 Editor，检查实际发现、完成、通过数量。地表高度和 TerrainWorkflow 已通过，包括合成 100 米地表下的 40 米绝对高度、相机 5 米间隙、未加载地表不回退为 0、抬升确认和地下目标拦截。原有 2D、两项 Camera Lock 和本地化隔离也已通过。

去重后，**8 个测试最终均有发现、完成和通过记录**，其中 6 项带既有环境告警。最终 build-5 补跑 TerrainWorkflow、原有 3D 数值回归及带真实视口的相机阻尼 / 路线测试，三项全部通过；其余通过记录保留在前序运行中。TerrainWorkflow 另检查有效的当前 20 米离地高度会被保留。

保留了初次失败：旧的 3D 数值回归默认按椭球高断言，与新 AGL 默认不一致，现通过显式选择高级椭球高模式验证原有精度，未放宽 0.0001 阈值；相机像素回归最初错误使用 NullRHI、视口为 0，现改用正常渲染环境重跑，非零视口断言保持不变。

12 个新增键已生成中英文资源，GatherText 内部退出码为 0；进程整体退出码为 1，仍有既有 GameFeatureData / Asset Manager 启动错误，不能称为完整无错误的本地化构建。界面中英文通过实际鼠标切换检查。

初次只读 Python 采样尝试由于 Blueprint 内部异步工厂未向 Python 暴露而失败，没有取得地表数值；该 Editor 退出时还发生 CesiumEditor 异步 ion session 崩溃。随后使用 C++ 碰撞采样和原生地图取得上述证据。首次 C++ 编译也保留了诊断代码多余 `ToSharedRef` 的失败日志。原始诊断日志留在 Saved，公开记录保存其散列及错误说明。

以上为 Mock 软件与在线地图验证；没有真实无人机执行证据，持续右键 / 中键相机拖动也不在本次原生验证范围。

最终 build-5 已通过正常启动器恢复 Command / Map / Video，三个角色均 ONLINE / hydrated；随后在用户原会话中用鼠标确认了同一垂直恢复，执行记录从 8 个已完成记录增加到 12 个，新增四机全部 COMPLETED，最终椭球高 79.109016 米，离地约 30–30.4 米。经纬度保持不变，Video 状态与恢复前完全相同。截图 `11`–`16` 记录最终标签、换行提示、预览、确认与完成。独立 QA 进程全部停止，用户正常会话保持运行。
