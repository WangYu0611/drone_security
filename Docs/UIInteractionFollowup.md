# 无人机地图与方案任务交互修复

本次接续 [Figma 指挥中心 UI 接入](FigmaCommandIntegration.md)，目标工程为 `D:\CodexPublish\drone_security`。2026-10-20 用户确认沿用当前默认区域、固定 Mock 初始点，图标保持固定屏幕大小，并要求航线编辑期间可以移动视角。

## 行为与操作

- 按用户后续确认，Launcher 每次新建 Mock Backend 会话时，UAV-01～04 都在默认集合区归位，按编号向东排列，间隔 `2 m`。首架起点为纬度 `39.9807`、经度 `116.34703`、高度 `30 m`。具体重启边界、历史保留与验证见文末“启动归位与地图可见性”；它取代此前仅首次初始化、重启保留已移动位置的默认行为。
- Mock 位置带 `simulation` 和 `telemetry_source` 标识，REST 初始化和 WebSocket 更新使用同一来源。模拟 GPS 不表示真实设备已经连通；收到真实遥测后以真实数据为准。
- 地图无人机图标按固定屏幕尺寸绘制，缩放地图时保持大小。标签仍使用各无人机已有设置。
- 选中一架或多架无人机后，在地图选目标点，先查看预览，再明确确认移动。执行仍经过后端的权限、配置占用、无人机占用、目标与路径检查，使用现有暂停、恢复和终止流程。选择或移动无人机不会切换视频目标。
- 编辑安保方案航线时，左键用于航点操作，中键平移，滚轮缩放，3D 视角下右键旋转。进入编辑时取消旧相机惯性；自动跟随和自动聚焦继续关闭，避免正在编辑的视角被任务更新抢走。
- 总览按活动执行组列出任务，包含进行中、暂停、返航和待调度状态；显示任务、方案、参与无人机和进度。已结束任务退出活动列表。每条方案任务可进入对应任务详情，自由移动记录继续通过全局执行控件管理。
- 每个方案内持续显示任务列表，可逐项选择、执行或再次编辑。未部署方案先检查和部署；部署不会自动执行。已部署任务需单独确认执行，查看详情也不会启动任务。再次编辑已部署任务会创建新版本并定位到对应任务，保留原部署与执行快照。

## 状态与兼容边界

用户本次明确要求开放编辑时的手动视角移动，取代历史 Camera Lock 的全冻结行为。旧测试名称 `DroneOps.P54.RouteEditCameraLock` 保留，断言改为检查手动操作有效、自动聚焦受限、航点左键与相机手势分离。历史验收文档中的全冻结结论仅适用于当时版本。

方案任务操作保留配置租约、未保存草稿确认、版本校验和 Backend ACK。执行详情按 `PlanId + MissionId` 关联，避免把同方案的另一项任务当成当前任务。总览列表使用稳定的执行组身份，列表刷新后旧点击不会转而操作新行。

## 战术地图鼠标操作与重复移动（2026-10-20）

按用户后续确认的习惯，战术地图左键点选或拖框选择无人机，Shift 增选、Ctrl 切换选择；右键单击预览目的地，仍需明确确认后执行。中键拖动平移，右键拖动在 2D 中平移、在 3D 中旋转，滚轮缩放。右键拖动即使回到按下位置，也不会被当作移动点击。航线编辑期间保留航点操作和手动视角控制，禁用集群移动选点。

旧版本在“集群移动”模式忽略拖框，且执行中点击空白地图会先切到选点模式再拒绝移动。修复后左键选择不依赖当前集群模式；拒绝移动不会锁住选择。开始重新选择会清除旧移动预览，选择 ACK 到达后才能创建新预览。执行中仍可选择无人机，重复移动继续遵守后端的占用检查。

单架和多架地图移动均提交 `execution_group_move`。单架生成一条执行；多架以主选无人机为锚点，保留相对位置。Command 的集群控制卡也允许选择一架无人机，空选择仍禁用移动按钮。选择或移动不改变视频目标。

修复前已通过隔离 RHI 自动化复现“集群移动后拖框不发送选择请求”和“Command 单机移动按钮禁用”，失败记录保留于：

## 启动归位与地图可见性（2026-10-20）

用户确认“每次启动都让 Mock 无人机归位排列”。Launcher 新建并持有 Backend 后，使用唯一请求编号提交一次归位；复用正在运行的 Backend 或只重启 Map 等客户端不会重复归位。默认集合区保留，按 UAV 编号从西向东排列。后续按用户要求将间隔从 20 m 改为 2 m，启动视角同步收近，图标保持固定屏幕大小。

归位由 Backend 保存为新的位置基准。旧任务与轨迹保留，归位前文档另存快照；受影响且尚未结束的模拟任务终止，待调度任务取消并释放占用。当前会话的新移动接续新的位置基准，旧记录的时间戳不会把无人机拉回旧位置。真实遥测和关联的活动设备组受到保护，不因 Mock 归位被覆盖。选择无人机仍不切换视频目标。

生产 CesiumWorld 的小窗口截图复现了图标消失：投影坐标有效，但 NativePaint 使用窗口坐标检查桌面空间的地图边界，并使用桌面几何裁剪绘制。修复统一了无人机、执行覆盖层和方案平移覆盖层的坐标转换。首次打开 Map 等待位置快照后显示整组无人机；空选择时“定位”同样覆盖整组。初始化等待有时限，缺失设备不会永久阻止其他有效设备显示；手动操作可取消初始化聚焦。

扩大初始间距后，重复框选回归发现执行自动聚焦只计算单个成员的航线，可能让其他无人机离开画面。现以执行组为稳定聚焦单位，使用整组航线、起点和当前位置；自由移动还覆盖其他有效无人机位置，支持接着选择另一架。聚焦使用实际地图可见区域计算距离，继续遵守编辑锁，保持选择与视频目标。
