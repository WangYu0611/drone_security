适用：一台 Windows 电脑、Launcher + Command/Map/Video，**Mock 软件业务闭环演示**。本稿由静态审计及既有原生证据整理，本轮没有运行演示或修改数据。

## 演示前准备

1. 在目标工程 `C:\Users\wy331\Documents\UE5DroneControl-p5-2` 找到 `DroneSecurityLauncher.cmd`。运行环境需要 Python/Tk、UE5.8 Editor 和已有 Backend/UE 编译产物。路径配置在 `Launcher/config.json`。
2. 提前启动一次并人工确认四个组件就绪、Map 图层可见、窗口可聚焦。正式演示冷启动可能超过讲解预算，建议观众入场前完成启动，开场展示 READY 与布局。
3. 查看当前任务历史与 UAV 占用。审计时 Saved 有四个 Plan，执行记录为 Completed 9、Aborted 1、Paused 1；这是已存盘记录，不是实时状态。保留原数据；为演示挑选无活跃执行的 Mock UAV 或在获得业务允许后处理原任务。
4. 当前 UAV-01～04 的视频地址均为空。若只展示界面，提前说明空态；若承诺播放，先准备有授权的 Mock MP4/本地演示页，明确标注“演示源”，由操作者预先验证后再纳入演示。不要现场临时连接真实相机。本轮未做这些修改。
5. 地图采用经过现场检查的 2D 视图，确认四个航点都在当前视野内。不要为了掩盖遮挡临时改动真实坐标；新建演示航线时正常选择适合的演示范围即可。
6. 正式流程不展示 debug 注入、旧 arrays 控制或 Jetson 解锁；本稿的 Start/Pause/Return 都指 Mock。

## 可选恢复演示（另加 2–3 分钟）

在 Mock 正在运行时，只用 Launcher 重启 Command 或 Map，观察同一执行重新加载。若演示统一关闭，等待系统确认已持久暂停，再重开并明确 Resume。单独 Backend 重启会从持久记录续算，与统一关闭的暂停恢复不同。不要同时进行多个重启步骤，以免讲解不清。

Return Home、Abort 可在另一次专用 Mock 执行中展示：返航完成只说明返回独立模拟Home；Abort后不能Resume。不要在主流程即将正常完成时中止，却仍宣称本次四点任务完成。

## 现场故障降级

- 地图影像缺失：如实说明图层依赖；能确认坐标与路线时仅演示业务/几何部分，不能宣布地图完整通过。
- 视频空态：继续展示目标隔离和界面结构；不要把预留卡片当实时画面。
- Start被拒绝：按提示核对Map在线/Mock可用/活跃任务占用；不调用旧debug/arrays绕过。
- 进程异常：仅由Launcher操作owned进程并检查同一任务恢复；切到历史证据时标明“已保存记录”。

Demo Ready 结论：**条件就绪**。已保存软件闭环足以支撑13分钟讲解；正式现场仍需一次人工预演，尤其检查地图、空视频源和现存暂停任务。本轮审计不代替这次现场预演。
