# Stage 1 使用与演示操作手册

适用：一台 Windows 电脑、Launcher + Command / Map / Video，**Mock 软件业务闭环演示**。本手册于 2026-10-30 按当前源码、配置、界面文案和既有验收记录核对；本次文档更新没有重新运行完整原生演示或真实设备测试。主流程约 13 分钟，框选移动、手动接管与恢复演示可另行安排。

## 启动前准备

1. 在当前克隆的仓库根目录运行 `DroneSecurityLauncher.cmd`。本开发机的项目目录是 `D:\CodexPublish\drone_security`；其他电脑使用自己的克隆目录。新电脑先按 [Windows 首次运行指南](../First-Run-Windows.md) 安装依赖、下载 Git LFS 资源、编译并配置 Cesium 地图授权。源码更新后也要重新编译，不能用旧 EXE / DLL 代替新代码。
2. 启动器默认等待选择模式，演示时点 **“DEMO 启动（新加坡）”**。DEMO 使用本机 Backend `19880/19881` 和 `Saved/Stage1/data`，依次启动 Backend、Command、Map、Video。基础配置在 `Launcher/config.json`，本机覆盖放在不提交的 `Launcher/config.local.json`；默认 `auto_start=false`，明确改为 `true` 时按 `startup_mode`（默认 `demo`）自动启动。先运行 `CheckDroneSecurity.cmd`，再启动并确认四个组件就绪、地图可见、窗口可聚焦；窗口出现不等于连接就绪。
3. DEMO 使用在线实景 3D，起点为新加坡 The Meadow 草地。Map 启动中心为纬度 `1.279445`、经度 `103.862188`、椭球高 `15 m`；Mock 队列向东间隔 `3 m`。用“定位 / Locate”查看近处无人机，或按需要切换 2D / 3D。`15 m` 不是离地高度，也不代表自动贴地；地图中心与已有方案、航线不会自动一起迁移。详见 [地图起点与缓存](../MarinaBayStartup.md)。
4. **DEMO 每次新建其拥有的 Backend 都会按设置重置符合条件的 Mock 会话。** 当前默认 `mock_reset_on_start=true`：符合条件的活动 Mock 执行会终止，预约执行会取消，无人机回到启动队列；历史和重置前备份仍保留。附加到已有 Backend、仅重启 Command / Map / Video 不会触发该重置。需要保留执行用于恢复演示时，先阅读下方“重启与恢复”。
5. 新安装默认创建四架明确标注的 Mock UAV，视频地址为空。已有运行目录保留自己的登记、视频地址、Home、方案及历史，不能把默认数据当成当前现场状态。正式演示前检查实际任务占用和视频源；需要播放时，预先配置并验证有授权的演示源。无源时可展示空态和目标切换，不宣称已经直播。
6. 在线地图需要地图服务授权和可用网络；缓存不会保证完全离线可用。若网络依赖代理，按首次运行指南设置本机代理并预先确认加载。正式演示前完成着色器编译与地图预热，不把冷启动时间计入 13 分钟操作流程。

本稿的开始、暂停、恢复、返航和移动均指 Mock。使用 Launcher 的 **Focus** 放大窗口，**Arrange Windows** 恢复总览。普通配置操作与正在运行的任务控制分开显示；开始其他方案的配置，不代表原任务已暂停。

### 实时入口与本演示的区别

**“实时模式启动”** 使用 `8080/8081` 和 `Backend/config.yaml`，从仓库根目录运行，沿用该配置的注册表、UDP `port_map` 和业务数据；本机可通过 `realtime_backend_config` 覆盖配置路径。`Saved/Realtime` 保存启动器进程记录、启动器日志、Backend 标准输出和 UE 日志；Backend 自身文件日志仍按所选配置的 `log.file`，默认 `logs/backend.log`。实时分支不播种 Mock UAV、不生成 Mock fixture、不执行启动重置，也不创建或启用 `real_execution.json`、不自动开始飞行任务。

实时原点优先采用后端真实接收、非模拟、在线、有 GPS fix 且接收时间默认不超过 5 秒的有效无人机坐标；优先当前 active UAV，否则选最小 slot。AMSL 高程按与 UE 相同的 `GeoidSeparationMeters` 转为椭球高，配置来自 `Config/DefaultGame.ini` 及本机 `Saved/Config/WindowsEditor/Game.ini`。

有效无人机 GPS 可立即初始化；未取得时，实时启动提供默认 **8 秒**连接发现窗口（`realtime_device_wait`），之后才考虑电脑定位。有真实 `online` / `connecting` 无人机但 GPS 无效时，继续等 GPS，默认上限 **60 秒**，不用电脑位置替代。只有完全没有真实连接时才查询 Windows 系统定位，最长 **15 秒**（`realtime_computer_location_timeout`）。系统不给高度时以 0 m 仅作相机锚点，状态标记估计高程，不作为飞机位置或飞行高度。系统定位禁用、拒绝、不可用或超时就明确报错，不打开 UE 角色，不自动改权限，不猜测 IP 城市，也不回落到新加坡。旧 Backend 缺少定位时间能力时先重新编译。初始化后不因新 GPS 自动切镜头；重启 Map 重新按相同优先级定位。

切换模式前先 **Shutdown System / 关闭系统**。实时关闭不调用 Mock pause，不自动暂停真实执行；外部 Backend 不由 Launcher 停止。合成测试不构成实际电脑定位、无人机 GPS 或物理飞行验收，完整配置步骤见 [首次运行指南](../First-Run-Windows.md#实时模式)。下文 13 分钟流程使用 DEMO。

## 主流程：创建、部署、执行和查看视频

按钮名称以所选语言为准，以下使用当前中文含义并附必要英文词。

| 时间 | 操作 | 应看到的结果与处理 |
| --- | --- | --- |
| 0:00–0:45 | 展示 Launcher 与三个客户端 | Backend、Command、Map、Video 全部就绪。未就绪时先处理连接，不继续提交任务。 |
| 0:45–1:20 | Command 中查看无人机列表，选择可用 Mock UAV | 可见设备身份、分配及执行信息。Mock 可执行不等于真实硬件在线。 |
| 1:20–2:00 | Focus Map，使用定位，检查 3D 或 2D 地图 | 能识别所选飞机、地面和待演示区域。Command 也有独立的 2D 战术概览，路线编辑交给 Map。 |
| 2:00–2:45 | Command → 安保方案 → 新建方案，填写名称并提交 | 只有提交并确认后才新增方案，进入配置工作区；取消新建不会留下空方案。 |
| 2:45–3:15 | 在任务配置中选择无人机并保存 | 显示 Backend 确认的任务与成员。若有占用，查看占用者和任务，调整分配或处理原任务；不要绕过冲突。 |
| 3:15–4:15 | 进入地图航线编辑，Focus Map，添加四个邻近航点 | Map 与 Command 指向同一方案和任务。检查航点、高度基准、速度和预计时长；可手动平移、缩放、旋转视角。闭合航线至少需要三个航点，Stage 1 Mock 执行一圈。 |
| 4:15–4:45 | 点“保存草稿”，再点“完成航线编辑” | 保存成功后仍可继续编辑；完成航线编辑才退出该编辑会话。有未保存修改时按提示选择保存、放弃或继续编辑。 |
| 4:45–5:20 | 在 Command 查看部署前检查与当前方案复核 | 当前配置、任务、全部成员、路线及冲突信息一致。出现阻塞时修正后重新检查。 |
| 5:20–5:45 | 确认部署方案并等待成功提示 | 显示已部署及部署记录。**部署只激活并冻结配置，此时无人机尚未开始执行。** |
| 5:45–6:15 | 点“开始任务”，检查确认内容后开始 | 检查方案、任务、全部分配成员和路线。若启用定时启动，核对本地日期、时间及状态；否则明确选择当前要执行的操作。不可用时按提示处理连接、配置或占用。 |
| 6:15–6:50 | 查看 Command 执行信息与 Map | 由 Backend 确认的状态、进度、航点与位置持续更新；地图中的移动与执行记录对应。 |
| 6:50–7:10 | 点暂停并等待确认 | 显示 `PAUSED`，执行位置与进度停止。按钮点击本身不等于已暂停。 |
| 7:10–7:30 | 点恢复 | 同一执行恢复推进，无需重新部署。 |
| 7:30–8:45 | 观察执行完成与历史 | 以 `COMPLETED` 和实际进度为准。超过预算时明确暂停或继续等待；展示旧记录须标注历史，不能称当前任务已完成。 |
| 8:45–9:35 | 在 Map 点另一架无人机，再查看 Video | 地图标记或设备列表中的明确选机，在选择确认后切换 Video 主目标。无视频源时应显示该机身份及无源状态；主目标改变不证明视频已解码。 |
| 9:35–10:10 | 在 Video 显式选择其他设备；演示视图布局 | 观察切换中、成功或错误提示。当前是一主播放器加其他卡片入口，不能把卡片数量说成同时解码路数。Command 普通选机、任务分配和 Map 纯框选不自动切换视频。 |
| 10:10–10:45 | 在 Command 或 Video 切换中文 / English | 三端主要工作流语言同步，业务状态保留；若某处仍为固定语言，按实际界面说明。 |
| 10:45–11:30 | 查看方案历史、日志或告警 | 区分当前状态和历史记录；没有告警时说明空态。 |
| 11:30–12:20 | 说明真实设备接口与验证范围 | 当前演示为软件 Mock；接口或历史记录不构成本次真实飞行、真实摄像头或物理避障验收。 |
| 12:20–13:00 | 核对结果；需要结束时使用 Shutdown System | 对 Launcher 拥有的 Backend，活动执行按提示先持久化暂停，再关闭其拥有的进程；复用的外部 Backend 不自动暂停或停止。再次启动是否保留执行取决于启动重置设置，见下文。 |

## 重新编辑、返回列表与再次部署

1. 从安保方案列表打开需要修改的方案，再进入对应任务的编辑。已部署方案仍有未结束执行或预约时，先处理这些执行；不要把重新编辑当成中止任务。
2. 修改方案或任务信息，必要时进入 Map 修改路线。先完成当前航线编辑，再继续方案检查或退出配置。
3. 返回列表使用 **“← 安保方案”或“结束配置”**。有未保存内容时，根据提示选择“保存后继续”“放弃修改并继续”或留在编辑中。保存失败时先处理错误，避免误以为已退出成功。
4. **“返回方案配置”只返回配置工作区，不是返回方案列表。** 返回列表成功后仍可重新打开同一方案，已有方案不会因退出配置而删除。
5. 修改路线后重新完成检查、审阅和部署。轨迹冲突会使相应内容保留在草稿状态，并显示阻塞信息；退出配置不会绕过冲突。再次部署保留原部署记录，新的部署仍不自动开始执行。

当前操作与验证边界见 [方案配置工作流](../PLAN-Configuration-Workflow.md) 和 [编辑返回与视频联动](../EditReturnVideo.md)。

## Map 框选和自由移动

1. 在没有方案配置占用时，先点 **“框选无人机”**，再在地图拖出选择框。普通地图拖动不会自动进入框选；单击无人机仍可选择该机。
2. 确认选中的成员，点 **“下一步 · 选择目的地”**，按提示右键选择目标。可以“重新选点”、调整高度、查看坐标或“适配预览”。
3. 检查目标、成员、距离和高度后，点 **“确认移动 N 架”**。选机、选点和调整预览本身不会开始执行。
4. 开始后使用所显示执行组的暂停、恢复或终止控制。终止需再次确认，已终止执行不能继续恢复。

3D 移动默认输入“目标离地高度”，表示主选锚点相对目标地表的高度；面板同时显示地表及目标椭球高。高级按钮可切换到椭球高，2D 保留绝对高度移动；提交前检查面板当前高度基准，不能把两者混用。地表未加载或检查不通过时按提示处理，不能仅凭输入值判断可移动。纯框选保持原 Video 主目标；单击无人机的联动规则见主流程。方案配置期间隐藏新移动入口，但已活动执行组的暂停、终止控制仍可使用。

## 执行中单机手动接管

另选一次专用 Mock 任务展示，避免与主流程“自然完成”混淆：

1. 先确认目标无人机正在执行、暂停或返航中的**已部署任务**，然后在 Map 单独选中该机。
2. 右键选择移动目的地，检查“手动接管移动”预览、目标高度及提示。
3. 点 **“接管并移动”**。成功后该机原执行被终止，并创建独立移动；同一原任务的其他成员继续原执行。
4. 新移动可单独暂停、恢复或终止。到达目标后**不会自动恢复原任务**；原任务组的控制不控制这次独立移动。

仅部署但未开始、等待预约、已结束以及普通自由移动，不属于此处的接管对象。配置模式中不能开始接管。若提示任务状态变化或目标冲突，先重新核对并选择目标；不要假定旧执行已被结束。完整行为及真实适配器失败边界见 [手动接管说明](../ManualTakeover.md)。

## 重启与恢复

DEMO 正常退出使用 **Shutdown System** 或关闭 Launcher；只有 Launcher 拥有的 Backend 会按提示先持久化暂停活动 Mock 执行，再停止进程。复用的外部 Backend 不自动暂停或停止，需在业务界面自行处理执行。单组件 **Stop / Restart 不经过这一步统一暂停确认**；操作前先在业务界面暂停或结束需要保护的执行。实时模式不发送 Mock pause，也不自动暂停真实执行；不要用下表的 Mock 重置规则推断实时行为。

| 操作 | 当前行为 |
| --- | --- |
| 仅用 Launcher 重启 Command、Map 或 Video | 按 Backend 当前快照恢复客户端；不会重置无人机位置，也不会重新创建执行。 |
| Launcher 附加到已经运行且模式相符的兼容 Backend | 不执行启动重置，也不接管该外部 Backend 的进程生命周期。 |
| 默认 DEMO 设置下重启 Launcher 拥有的 Backend，或全停后再点 DEMO 启动 | 创建新的 Mock 会话并执行启动重置。符合条件的活动 Mock 执行转为 `ABORTED`，预约执行转为 `CANCELLED`，释放相应占用；位置回到 3 m 启动队列。不能用此流程演示原执行 Resume。 |
| 明确把本机 `mock_reset_on_start` 设为 `false` 后启动，或使用同一运行配置和数据目录直接启动 Backend | 不调用 Launcher 启动重置；从已持久化的执行状态恢复。统一关闭前已暂停的执行仍需明确 Resume；切换数据目录不会带回另一目录的执行。 |

需要演示保留执行时，**在下一次启动前**合并以下配置到 `Launcher/config.local.json`，保留该文件中其他本机设置；设置在 Backend 已重置后不能恢复被结束的执行：

```json
{
  "mock_reset_on_start": false
}
```

默认 DEMO 启动重置会在 `Saved/Stage1/data/mock-reset-history` 保存重置前完整文档，并保留方案、部署与历史。自定义 Home 文件不被覆盖，历史路线也不会平移到新起点。检查新会话位置和旧路线是否处于同一区域后再开始任务。真实遥测、真实执行保护以及被跳过的组以 Backend 返回结果为准。

Return Home 和 Abort 可另行展示：返航完成表示模拟位置到达有效 Home，不能证明真实飞机落地；Abort 后不能 Resume。不要同时操作多个组件重启，以免无法判断是哪一步改变了状态。

## 现场问题处理

| 现象 | 检查与操作 |
| --- | --- |
| 地图黑屏、局部空白或加载很慢 | 检查 Cesium 授权、网络或本机代理，等待当前区域加载。缓存已扩容，但未证明固定加速倍数，也不是完整离线地图包。缺失地形时如实限定演示范围。 |
| 看不到间隔 3 m 的单个无人机 | 使用定位并拉近视角；城市总览不保证每架飞机都有独立的屏幕占位。 |
| 退出后仍在方案配置 | 区分“返回方案配置”和“← 安保方案 / 结束配置”，完成路线编辑并处理未保存提示；有错误时按提示解决。 |
| 无法部署或开始 | 阅读具体冲突、成员不可用或占用者提示；检查当前方案修订、全部分配无人机及 Map 连接。不要通过旧 debug / arrays 接口绕过检查。 |
| 点 Map 无人机后 Video 尚未切换 | 等待选择及视频目标确认，检查客户端在线状态和错误提示；纯框选或点空地不触发切换。 |
| Video 无源、等待画面或卡住 | 核对当前目标和该机视频地址。无源先配置可用源；加载失败或有源无帧时按界面重试。目标已切换与画面成功播放是两件事。 |
| 进程异常 | 用 Launcher 管理它拥有的组件，查看 `Saved/Stage1/Logs`。重启 Backend 前核对启动重置设置；不要清库或批量强杀同名程序。 |

实际演示前仍需一次人工预演，确认当日地图网络、视频源、资源占用和当前任务状态。本手册是操作说明；既有原生鼠标、组件自动化、Mock 执行和真实设备证据各自独立，最近的交互验收见 [InteractionUX 验收记录](../../Evidence/InteractionUX/20261023/acceptance.json)。
