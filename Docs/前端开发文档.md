# UE5 前端开发文档（当前实现）

> 更新时间：2026-09-09
> 工程版本：Unreal Engine 5.7，模块 `Source/UE5DroneControl/`。
> 本文区分“源码中存在”和“已在 UE 5.7 Play Mode 验收”；后者必须有编辑器/运行日志或人工操作证据。

## 1. 前端职责

UE 负责三维场景和用户交互：

- `UDroneNetworkManager` 统一拥有 HTTP 客户端、WebSocket 客户端和 3 秒注册表轮询。
- `UDroneRegistrySubsystem` 保存本地镜像的身份、遥测、连接状态、任务状态和选择状态。
- `ADroneOpsPlayerController` 处理地图点击、无人机选择、镜头/控制交互，并把目标点交给网络管理器。
- `ARealTimeDroneReceiver`、`AMultiDroneCharacter` 等 Actor 订阅 Registry/网络事件，分别承担镜像显示和影子/预演显示。
- `USequenceDispatchPanelWidget`、`ADronePathActor`、`ADronePlaybackManager` 负责路径编辑、预演和阵列派发。
- `UDroneVideoWindowWidget` 通过 UE WebBrowser 加载后端返回的 MediaMTX 浏览器播放页。

UE 不拥有后端注册表、GPS 锚点、NED 控制目标或飞控执行事实。后端返回的 HTTP 2xx 也不等同于 Jetson/PX4 已执行。

## 2. 网络配置

默认配置在 `Config/DefaultGame.ini`：

```ini
[/Script/UE5DroneControl.DroneNetworkManager]
BackendBaseUrl="http://127.0.0.1:8080"
WebSocketUrl="ws://127.0.0.1:8081/ws"
PollIntervalSec=3.0
GeoidSeparationMeters=0.0
```

外场只需把 `BackendBaseUrl`、`WebSocketUrl` 改为后端机器地址，不要在 C++ 中硬编码新地址。`DroneWebSocketClient` 初始化 WebSocket 上下文时会临时清除 UE HTTP 代理，避免本机/内网 WS 被代理；当前 `DefaultEngine.ini` 的在线 HTTP 代理 `127.0.0.1:7890` 是本机环境值，换机器需复核。

## 3. 网络层调用关系

```text
UGameInstance
  └─ UDroneNetworkManager
      ├─ UDroneHttpClient  ── GET /api/drones（每 3 秒）
      │                     ├─ POST /api/drones
      │                     ├─ POST /api/drones/refresh
      │                     ├─ POST /api/arrays
      │                     └─ POST /api/arrays/a1/stop
      └─ UDroneWebSocketClient ── ws://<host>:8081/ws
                                ├─ 发送 move / scout / patrol / attack
                                ├─ 发送 pause / resume
                                └─ 接收 telemetry / event / alert / task
```

### 3.1 实时目标点

`UDroneNetworkManager::SendMoveCommand()` 发送：

```json
{"mode":"move","drone_id":"1","x":1000,"y":2000,"z":500,"speed":1.0,"coalesce_queued_vertical_targets":false,"coalesce_queued_manual_targets":false}
```

`x/y/z` 必须是对应无人机上电锚点下的 UE 相对偏移，单位 cm；速度为 m/s，有限值在后端归一化到 `[0.5,15]`，0 表示兼容的无限速标记。`DroneOpsPlayerController` 在单机实时控制路径中负责把世界坐标减去该机的 `AnchorWorldLocation`；改动这条链路时必须同时检查 `SendTargetCommand()` 和 `SendMoveCommand()` 的调用点。

### 3.2 WebSocket 下行事件

网络管理器当前分发：

| 消息 | UE 侧入口/用途 |
|---|---|
| `telemetry` | 更新 `UDroneRegistrySubsystem`，驱动镜像 Actor/UI |
| `event` | `OnDroneWsEvent`，处理 `power_on`、`reconnect`、`lost_connection` 及 GPS 锚点缓存 |
| `alert` | `OnDroneWsAlert`，低电量/断联提示 |
| `assembling` | `OnAssemblingProgress`，更新集结进度 |
| `assembly_complete` | `OnAssemblyComplete`，放行等待集结的在线影子机 |
| `assembly_timeout` | `OnAssemblyTimeout`，停止或提示失败 |
| `assignment_result` | `OnAssignmentResult`，同步自动分配的 path→drone 映射 |
| `drone_task_state` | 更新任务状态、航点索引和详情 |
| `command_ack` / `error` | 记录后端接受结果或错误 |

后端遥测的 `x/y/z` 是相对偏移，不是 Cesium 世界坐标；UE 需要在有 GPS 锚点时把它放回世界场景。

## 4. 当前功能状态

下表是代码级状态，不代替 Play Mode 验收：

| 功能 | 当前代码事实 | 仍需验证 |
|---|---|---|
| HTTP/WS 客户端 | `DroneHttpClient` 支持 GET/POST/PUT/DELETE；WS 有连接、关闭、自动重连 | 后端真实地址、断线重连、错误 UI |
| 注册表同步 | 轮询 `GET /api/drones` 并同步 Registry | UE 5.7 运行时 UI 显示和注册操作 |
| 单机 move | 通过 WS 发送 `mode` 目标 | 锚点、真实后端和飞控 `control_ack` |
| 暂停/恢复 | 发送 `pause`/`resume` 和 `drone_ids` | 多机 UI 操作和后端状态反馈 |
| 阵列派发 | `POST /api/arrays`，支持 `scout/patrol/attack`、闭环、速度/等待字段 | 多机不同上电原点的外场坐标正确性 |
| 自动分配 | `auto_assign=true` 时等待 `assignment_result` | 真实在线列表、代价矩阵和用户验收 |
| 集结门控 | 在线真机影子机可以等待 `assembly_complete`；mock/无锚点路径可本地播放 | 真机 Play Mode 时序和取消清理 |
| 本地严格预演 | `bStrictLocalPreview`/运行时 isolation 可停止轮询、断 WS、取消 HTTP、阻止写请求 | 关卡切换及 UI 提示 |
| 视频窗口 | 从 `video_url` 加载 MediaMTX WebRTC 页面，关闭时导航到 `about:blank` | 浏览器页面/WebRTC/多窗口实机播放 |
| 离线 Cesium | `DroneOpsGameMode` 读取 `CesiumTileServer` 并切换 URL overlay/离线平面 | 本地 tile server、影像坐标和视觉效果 |

## 5. 阵列派发契约

路径请求大致为：

```json
{
  "mode":"scout",
  "auto_assign":false,
  "paths":[
    {
      "pathId":1,
      "drone_id":"1",
      "bClosedLoop":false,
      "waypoints":[
        {"location":{"x":1000,"y":0,"z":500},"segmentSpeed":3.0,"waitTime":0.0}
      ]
    }
  ]
}
```

代码使用 `UDroneNetworkManager::SendArrayTask()`/`SendArrayTaskFromData()`，自动分配时清空 `drone_id` 并由后端推送 `assignment_result`。后端仍把 waypoint 解释为目标机上电原点下的 UE 相对偏移；当前路径重映射代码存在 Cesium/UE 世界坐标直接进入该入口的风险，外场前必须验证每个执行机的原点补偿。

停止当前 UE 阵列使用 `POST /api/arrays/a1/stop`。这里的 `a1` 是当前 UE 默认提交和后端单活动阵列的约定，不要把它当作通用多任务 ID 生成规则。

## 6. 坐标和 GPS 锚点

1. 后端由 Jetson YAML 保存 GPS 锚点，并通过 `power_on`/`reconnect` 事件推送。
2. UE 的 `ARealTimeDroneReceiver`/`AMultiDroneCharacter` 接收事件，将 WGS84 经纬高交给 `CesiumCoordinateService` 或 Georeference。
3. 遥测 `x/y/z` 经过锚点放回 UE 世界；控制时从 UE 世界坐标减去同一机的锚点。
4. `GeoidSeparationMeters` 用于 `椭球高 = 海拔正高 + GeoidSeparationMeters`，默认 `0.0` 仅是配置默认值。

多机不共享一个 NED 原点。公共地理目标需要对每架机分别计算相对偏移；不能复用参考机的偏移。

## 7. 本地预演与后端隔离

启用 `bStrictLocalPreview=true`，或在运行时调用 `SetStrictLocalPreviewIsolation(true)` 时，网络管理器会：

- 停止 `GET /api/drones` 轮询；
- 取消在途 HTTP；
- 断开 WebSocket 并禁用自动重连；
- 阻止注册、refresh、move、pause/resume、array/stop 等后端写请求；
- 广播 isolation 状态，供列表和派发 UI 显示“纯本地预演模式已阻止后端通信”。

关闭隔离后会恢复 WS、轮询并立即同步一次注册表。`bStrictLocalPreview` 是配置初值，运行时状态以 `IsStrictLocalPreviewIsolation()` 为准。

```powershell
# 后端启动后检查
curl.exe http://127.0.0.1:8080/

# 前端代码入口
# Source/UE5DroneControl/DroneOps/Network/DroneNetworkManager.*

# Source/UE5DroneControl/UI/SequenceDispatchPanelWidget.*
```

静态编译只能证明 C++/UHT 可构建；视频 WebRTC、Cesium 地理对齐、UE UI、真实跨机网络和飞控运动要在 UE 5.7 编辑器/Play Mode 或外场记录证据。
